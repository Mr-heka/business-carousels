# Official host documentation

Checked 3 October 2026. Apps and plans change; the tools your session actually shows decide what works.

| Topic | Source | Used for |
| --- | --- | --- |
| Claude image capability | [Can Claude produce images?](https://support.claude.com/en/articles/9002504-can-claude-produce-images) | Claude builds diagrams, charts and visuals with HTML and SVG and can analyse uploaded images; it doesn't generate photos or illustrations like image-generation tools. |
| Claude skill upload | [Use Skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude) | Code execution setting, Customize > Skills > Upload a skill, plan availability. |
| Claude skill format | [How to create custom Skills](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) | ZIP contains the skill folder at its root; name up to 64 characters; description up to 200 characters. |
| Claude Code skills | [Extend Claude with skills](https://code.claude.com/docs/en/skills) | User skills live in `~/.claude/skills/<name>/` with supporting files beside `SKILL.md`. |
| Codex skills | [Build skills](https://learn.chatgpt.com/docs/build-skills) | User skills live in `~/.agents/skills/<name>/`. |
| Images in ChatGPT | [Images in ChatGPT](https://help.openai.com/en/articles/11084440-images-in-chatgpt) | Image generation depends on the account and session. |
